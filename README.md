### 👨‍💻 Обо мне

Привет! Я **веб-разработчик**, увлечённый созданием быстрых, интерактивных и архитектурно выверенных веб-приложений. 

- 🌐 **Специализация:** Разработка полного цикла (Frontend + Backend), создание RESTful и real-time API, интерактивных веб-сервисов и мобильных решений.
- 🎨 **Эстетика:** Ценю строгий минимализм, продуманный UX/UI и высокую отзывчивость интерфейсов.
- 🧪 **Creative & R&D Tech:** Люблю сложные технические вызовы — от реалтайм-сетей на WebSockets и синтеза звука через Web Audio API до нейроморфных симуляций и машинного обучения на PyTorch.
